# GeoMeasure G (googlemap_coverage)

게이트웨이 커버리지(반경) 확인용 지도 측정 도구 — **Google Maps 판**.
지점 좌표 확인 · 경로 거리 측정 · 지점별 반경원 표시 · 영역(다각형) 주석 · 지도 위 텍스트 · GPS 추적 · GeoJSON 저장을 제공한다.

## 계보 / 출처

이 도구는 두 단계를 거쳐 왔다.

```
dream2k2/gmap-plus-fsm-   원본 GeoMeasure (Google Maps)
        │                 지점·거리·반경원이라는 도구의 뼈대
        ▼
pye0828-lab/kakaomap_coverage   GeoMeasure K (카카오맵 스카이뷰)
        │                 국내 최신 위성영상으로 엔진 교체.
        │                 영역·텍스트·GeoJSON 저장이 여기서 자람
        ▼
   이 저장소            GeoMeasure G (Google Maps)
                        K 의 기능을 다시 Google Maps 로 이식
```

- **원본**: [dream2k2/gmap-plus-fsm-](https://github.com/dream2k2/gmap-plus-fsm-) — [실행본](https://dream2k2.github.io/gmap-plus-fsm-/). LICENSE가 없어 원칙상 원작자 저작권이 살아있으므로 화면과 이 문서에 출처를 남긴다.
- **국내판**: [pye0828-lab/kakaomap_coverage](https://github.com/pye0828-lab/kakaomap_coverage) (GeoMeasure K)
- **기능 동기화 기준 커밋**: `kakaomap_coverage @ be7a4d3`
  — *"측위가 화면을 망치던 문제들 수정 및 위치 차단 헤더 대응"* (2026-08-06)

즉 원본 → K → G 로 **지도 엔진만 두 번 바뀌고 기능은 이어져 왔다.** 이 저장소는 원본의 fork도, K의 fork도 아닌 독립 저장소다.

## K 와 G, 무엇을 쓰나

| | GeoMeasure K | GeoMeasure G |
|---|---|---|
| 지도 | 카카오맵 스카이뷰 | Google Maps 위성 |
| 국내 위성영상 | **최신** | 오래된 지역이 많음 |
| 해외 | ❌ 카카오맵은 국외 지도 데이터 없음 | ✅ 전세계 |
| API 키 | 무료·카드 불필요 | **결제 계정 필요** (무료 한도만 써도) |
| 한도 초과 시 | 요청 차단(과금 없음) | 과금 — 할당량 상한을 직접 걸어야 함 |

**국내 현장은 K, 해외 현장은 G.** 둘 사이의 데이터 이동은 GeoJSON 파일로 한다.

## 기능

- 장소/좌표 검색 (검색 마커는 클릭으로 제거 — 지도 위치는 유지)
- GPS 현재 위치 확인 및 실시간 추적 (측위 정확도 ± 표시, 오차에 맞춰 배율 조정)
- 지도 탭으로 지점 추가, 지점 간 경로 거리 자동 계산 (폐합 둘레 포함)
- 지점별 반경원(커버리지) 표시, 마커 드래그로 위치 조정, 지점 이름 지정
- **영역(폴리곤)** — 방목지·농장경계를 다각형으로 그리고 채움색·선색·투명도 지정, 면적 자동 계산
- **지도 위 텍스트** — 영역 이름·설명과 독립 텍스트, 라벨은 드래그로 위치 조정
- **GeoJSON 내보내기/불러오기** — 파일 하나 = 목장 하나, 드래그앤드롭 지원, 작업 자동저장
- 지도 타입 전환(**위성+** / 위성 / 위성+라벨 / 일반 / 지형)

### 위성+ (기본값)

Google 위성영상은 지역마다 원본 이미지가 존재하는 배율이 정해져 있다(국내 농촌은 보통 19~21레벨). 그 위로 확대하면 **"죄송합니다. 이미지가 없습니다"**가 뜨고 화면이 빈다 — 축사 지붕과 설치 지점을 짚어야 하는 도구라 하필 그 배율에서 쓸모가 끊긴다.

**위성+**는 원본 이미지가 있는 마지막 배율의 타일을 잘라 확대해 채운다. 실제로 더 선명해지지는 않지만 화면이 비지 않고, **축척·마커·반경원·거리는 계속 정확하다**(지도 좌표계를 그대로 쓰므로).

**위성 / 위성+라벨**을 고르면 `MaxZoomService`로 그 지역의 이미지 한계까지만 확대되도록 잠근다. 한계에 닿으면 안내가 뜨고 더 확대되지 않는다 — 빈 화면을 보는 일이 없다.

> ⚠️ 위성+는 문서화되지 않은 Google 타일 엔드포인트(`mt0~3.google.com/vt`)를 쓴다. API 키·할당량·과금을 타지 않는 대신 **Google Maps Platform 약관이 허용하는 경로가 아니고, 막히면 예고 없이 끊긴다.** 원본 GeoMeasure와 화면을 맞추기 위해 위험을 알고 채택했다(2026-08-06). 끊기면 이 레이어만 제거하고 기본값을 `위성`으로 되돌리면 된다 — 이미지 한계 잠금은 공식 API만 쓰므로 그대로 살아있다.

### 모드

지도 클릭의 주인이 셋 중 하나다. 상단 고정 바에서 전환한다.

| 모드 | 지도 클릭 |
|---|---|
| 📏 측정 | 측정 지점 추가 |
| ⬟ 영역 | 다각형 꼭짓점 추가 (**첫 꼭짓점을 다시 클릭**하면 닫힘) |
| 👁 보기 | 무시 (라벨 드래그는 가능) |

> 영역을 닫는 방법이 K와 다르다. K(카카오)는 더블클릭·우클릭, G(구글)는 첫 꼭짓점 재클릭이다.
> G의 영역 그리기는 **직접 구현**이다 — 구글이 Maps JS 3.65에서 `drawing` 라이브러리를 걷어냈다(CLAUDE.md §5.6). 조작법은 그 전과 같다.

### 저장 포맷

자체 JSON이 아니라 **GeoJSON**을 쓴다. 지도 엔진을 바꿔도 현장 데이터가 살아남아야 하기 때문이고, 그 덕에 **K와 G가 파일을 그대로 주고받는다.**

| 항목 | geometry | properties |
|---|---|---|
| GW 커버리지 | Point | radius, label, name, color |
| 영역 | Polygon | name, desc, fillColor, strokeColor, opacity, labelPos |
| 텍스트 | Point | text, fontSize |
| 측정 경로 | LineString | — |

거리·면적처럼 **계산으로 나오는 값은 저장하지 않는다**(좌표를 옮겼을 때 어긋난 파일이 된다). 반경은 사용자가 정한 값이라 저장한다. 경로 LineString은 외부 뷰어용으로 내보내되, 불러올 때는 무시하고 GW 지점에서 다시 그린다.

`properties.app`은 표기용일 뿐 **불러오기가 검사하지 않는다** — K가 내보낸 파일이 그대로 열린다. 불러오기는 신뢰 경계로 취급해 좌표 범위·타입·필수 필드를 검증하고, 버린 항목은 사유를 화면에 남긴다.

> ⚠️ **localStorage 자동저장 키는 K와 다르다**(`geomeasure.g.v1`). 같은 호스트에 두 판을 올리면 localStorage를 공유하므로, 키가 같으면 한쪽 작업이 다른 쪽을 덮어쓴다. 두 판 사이의 데이터 이동은 GeoJSON이 담당한다.

## 사용 / 설정

정적 HTML 한 파일이라 별도 빌드가 필요 없다. 웹서버에 `index.html`을 올리면 동작한다.

단, **Google Maps JavaScript API 키**가 필요하다. [Google Cloud Console](https://console.cloud.google.com/google/maps-apis)에서 아래를 설정한다. **하나라도 빠지면 지도가 안 뜬다.**

### 1. API 사용 설정

- **Maps JavaScript API** — 지도 표시 (필수)
- **Geocoding API** — 장소/주소 검색 (검색을 안 쓸 거면 생략 가능)

### 2. 결제 계정 연결

**무료 한도만 쓰더라도 결제 계정(해외결제 가능 카드) 연결이 필수다.** 카카오와 결정적으로 다른 점이다.

### 3. 키 발급 후 코드에 넣기

`index.html`의 `GMAPS_KEY` 상수에 JavaScript API 키를 넣는다.

```js
const GMAPS_KEY='여기에_키';
```

임시 확인은 주소 끝에 `?key=발급키`를 붙여도 된다(파일을 고치지 않아도 됨).

### 4. 키 제한 — HTTP 리퍼러

키 제한을 **HTTP 리퍼러(웹사이트)** 로 설정하고 서비스할 주소를 등록한다. 구글 JS 키도 카카오와 마찬가지로 클라이언트에 노출되는 것이 정상이며, 리퍼러 제한이 보호 수단이다.

### 5. 할당량 상한 — 과금 방지 (중요)

**예산(Budget) 알림은 사용을 막지 않는다.** 알림만 보내고 과금은 계속된다. 실제로 막으려면 **할당량(Quota) 상한**을 걸어야 한다.

| | 월 무료 | 일 상한 권장 |
|---|---|---|
| Maps JavaScript API (Dynamic Maps) | 10,000 | 300 |
| Geocoding API | 10,000 | 300 |

무료 한도는 **월** 단위인데 할당량 설정은 **일** 단위다. `10,000 ÷ 31 ≈ 322`이므로 300 정도로 잡으면 월 무료를 넘지 않는다. API마다 별도 SKU라 **각각 걸어야** 한다.

한도를 넘으면 지도가 안 뜨고 화면에 안내가 표시된다 — 과금이 아니라 정지다.

### 지도가 안 뜰 때

화면에 현재 origin과 함께 원인 후보가 표시된다. 브라우저 콘솔 오류로도 가릴 수 있다:

| 오류 | 원인 | 조치 |
|---|---|---|
| `BillingNotEnabled` | 결제 계정 미연결 | 2번 |
| `RefererNotAllowed` | 리퍼러 제한에 현재 주소 없음 | 4번 |
| `ApiNotActivated` | Maps JavaScript API 미활성화 | 1번 |
| `InvalidKey` | 키 문자열 오류 | 3번 |
| `OverQuota` | 할당량 초과 | 5번 (의도한 정지) |
| 검색만 `REQUEST_DENIED` | Geocoding API 미활성화 | 1번 |
| 검색 시 "지도 로딩 후 다시 시도하세요" | 키 문제가 아니다 — `initMap`이 중간에 끊겨 `geocoder`가 안 만들어진 것 | 콘솔에서 `초기화 실패:` 경고를 찾는다. 화면에도 같은 내용이 뜬다 (CLAUDE.md §5.6) |

## 자체 점검

지도 SDK 없이 순수 로직만 확인한다. **API 키가 없어도 돌아간다** — 이 저장소는 키 확보 전에 작성됐으므로 특히 중요하다.

**브라우저에서 거리만 빠르게 보기**

```
index.html?selfcheck=1
```

**전체 검증 (거리 · 면적 · GeoJSON 파싱 · 입력 검증 · K 호환)**

```
node selfcheck.test.js
```

의존성·프레임워크 없이 `node`만 있으면 된다. `index.html`의 인라인 스크립트를 **매번 그대로 추출해** 돌리므로 사본이 갈라지지 않는다.

기준값은 원본 도구로 측정한 용춘목장 3지점(A↔B 196.7 m · B↔C 237.9 m · C↔A 355.5 m)이며, **K와 같은 값이어야 한다** — 다르면 두 판이 파일을 주고받는 의미가 없어진다. K가 내보낸 파일을 그대로 읽는지, 남반구·서반구 음수 좌표가 통과하는지도 함께 검증한다.

## 검증 상태

| 항목 | 상태 |
|---|---|
| 순수 로직 (거리·면적·GeoJSON·입력검증) | ✅ `node selfcheck.test.js` 60건 통과 |
| K와의 계산 결과 일치 | ✅ 대조 확인 |
| 웹서버 배포 (경로·문서차단·위치헤더) | ✅ 2026-08-06 적용 확인 (아래 «배포») |
| 위성+ 타일 좌표 계산 | ✅ selfcheck 6건 + 실제 타일 URL 200 응답 확인 |
| **지도 렌더·드로잉·측위** | ⏸ **미검증** — 실제 브라우저 확인 필요 |

배포는 끝났지만 **지도가 실제로 뜨는지는 아직 사람 눈으로 확인되지 않았다.** 키 인증(리퍼러·결제·API 활성화)은 브라우저에서만 판정되며, `curl`로는 가릴 수 없다 — 직접 호출한 `AuthenticationService`는 리퍼러와 무관하게 같은 오류를 돌려주므로 검증 수단이 되지 못한다.

브라우저로 서비스 주소를 열어 다음을 확인한다: 지도 표시 · 지점 추가/드래그 · 반경원 · 영역 그리기(첫 꼭짓점 재클릭으로 닫기) · 라벨 드래그 · 지도타입 5종 · **위성+에서 21~22레벨까지 확대해도 "이미지가 없습니다"가 안 뜨는지** · **위성 모드에서 한계 안내가 뜨고 더 확대되지 않는지** · 검색 · GPS · K 파일 불러오기. 지도가 회색이면 화면에 원인이 표시되므로 «지도가 안 뜰 때» 표로 넘어간다.

> 기본값이 위성+로 바뀐 뒤로는 **키가 잘못돼도 타일은 그려진다**(그 레이어는 키를 타지 않는다). 키 확인은 화면의 인증 오류 안내와 검색 동작으로 판정한다.
