# GeoMeasure G (googlemap_coverage)

게이트웨이 커버리지(반경) 확인용 지도 측정 도구 — **Google Maps 판**.
지점 좌표 확인 · 경로 거리 측정 · 지점별 반경원 표시 · 영역(다각형) 주석 · 지도 위 텍스트 · GPS 추적 · GeoJSON 저장을 제공한다.

## 계보 / 출처

이 도구는 두 단계를 거쳐 왔다.

```
dream2k2/gmap-plus-fsm-   원본 GeoMeasure (Google Maps)
        │                 지점·거리·반경원이라는 도구의 뼈대
        ▼
pye0828-lab/kakaomap_coverage   GeoMeasure K (카카오맵 스카이뷰)
        │                 국내 최신 위성영상으로 엔진 교체.
        │                 영역·텍스트·GeoJSON 저장이 여기서 자람
        ▼
   이 저장소            GeoMeasure G (Google Maps)
                        K 의 기능을 다시 Google Maps 로 이식
```

- **원본**: [dream2k2/gmap-plus-fsm-](https://github.com/dream2k2/gmap-plus-fsm-) — [실행본](https://dream2k2.github.io/gmap-plus-fsm-/). LICENSE가 없어 원칙상 원작자 저작권이 살아있으므로 화면과 이 문서에 출처를 남긴다.
- **국내판**: [pye0828-lab/kakaomap_coverage](https://github.com/pye0828-lab/kakaomap_coverage) (GeoMeasure K)
- **기능 동기화 기준 커밋**: `kakaomap_coverage @ 1e7f540`
  — *"지침: 브랜치를 만들지 않는 것으로 §1.2·§3.3.1 수정"* (2026-08-11)

즉 원본 → K → G 로 **지도 엔진만 두 번 바뀌고 기능은 이어져 왔다.** 이 저장소는 원본의 fork도, K의 fork도 아닌 독립 저장소다.

## K 와 G, 무엇을 쓰나

| | GeoMeasure K | GeoMeasure G |
|---|---|---|
| 지도 | 카카오맵 스카이뷰 | Google Maps 위성 |
| 국내 위성영상 | **최신** | 오래된 지역이 많음 |
| 해외 | ❌ 카카오맵은 국외 지도 데이터 없음 | ✅ 전세계 |
| API 키 | 무료·카드 불필요 | **결제 계정 필요** (무료 한도만 써도) |
| 한도 초과 시 | 요청 차단(과금 없음) | 과금 — 할당량 상한을 직접 걸어야 함 |

**국내 현장은 K, 해외 현장은 G.** 둘 사이의 데이터 이동은 GeoJSON 파일로 한다.

## 기능

- 장소/좌표 검색 (검색 마커는 클릭으로 제거 — 지도 위치는 유지)
- GPS 현재 위치 확인 및 실시간 추적 (측위 정확도 ± 표시, 오차에 맞춰 배율 조정)
  - 지도 위 **현재위치 표시는 끌 수 있다** — 오차가 크면 파란 오차원이 화면을 덮어 지점·반경원을 가린다. 꺼도 좌표·거리 계산은 그대로 돈다
- 지도 탭으로 지점 추가, 지점 간 경로 거리 자동 계산 (폐합 둘레 포함)
- 지점별 반경원(커버리지) 표시, 마커 드래그로 위치 조정, 지점 이름 지정
- **위치 고정(잠금)** — 드래그로 지점·텍스트가 움직이는 것을 막는다. 모바일에서 두 손가락 확대 중 좌표가 바뀌는 사고를 막기 위한 것이고, **가져오거나 복원된 작업은 자동으로 잠긴다** (아래 "위치 고정")
- **지점 순서 변경(▲▼)** — 지점은 항상 목록 끝에 붙는다. 빠뜨린 곳을 나중에 찍었으면 지우고 다시 찍지 말고 끌어올린다(지우면 붙여둔 사진까지 날아간다). 순서는 표시가 아니라 계산이다 — 구간 거리·총거리·폐합 둘레가 전부 이 순서로 나온다
- **지점 이름은 마커 아래에 같이 표시된다** — 산출물이 화면 캡처라 이름이 그림에 남아야 한다. 이름을 적은 지점만 표시되고(안 적으면 원 안의 A·B·C 뿐), 10자를 넘으면 줄여서 그린다
- **사진 첨부** — GW 설치 사진을 **지점 또는 텍스트**에 붙이고 파일 하나로 같이 오간다 (아래 "사진 첨부")
- **영역(폴리곤)** — 방목지·농장경계를 다각형으로 그리고 채움색·선색·투명도 지정, 면적 자동 계산
- **지도 위 텍스트** — 영역 이름·설명과 독립 텍스트, 라벨은 드래그로 위치 조정, 놓인 **좌표를 눌러 복사**
- **GeoJSON 내보내기/불러오기** — 파일 하나 = 목장 하나, 드래그앤드롭 지원, 작업 자동저장
- **구글 드라이브에서 불러오기** — 공유 링크를 붙여넣거나, `?gd=` 주소 하나로 열자마자 불러온다 (아래 "드라이브에서 불러오기")
- 지도 타입 전환(**위성+** / 위성 / 위성+라벨 / 일반 / 지형)

### 위성+ (기본값)

Google 위성영상은 지역마다 원본 이미지가 존재하는 배율이 정해져 있다(국내 농촌은 보통 19~21레벨). 그 위로 확대하면 **"죄송합니다. 이미지가 없습니다"**가 뜨고 화면이 빈다 — 축사 지붕과 설치 지점을 짚어야 하는 도구라 하필 그 배율에서 쓸모가 끊긴다.

**위성+**는 원본 이미지가 있는 마지막 배율의 타일을 잘라 확대해 채운다. 실제로 더 선명해지지는 않지만 화면이 비지 않고, **축척·마커·반경원·거리는 계속 정확하다**(지도 좌표계를 그대로 쓰므로).

**위성 / 위성+라벨**을 고르면 `MaxZoomService`로 그 지역의 이미지 한계까지만 확대되도록 잠근다. 한계에 닿으면 안내가 뜨고 더 확대되지 않는다 — 빈 화면을 보는 일이 없다.

> ⚠️ 위성+는 문서화되지 않은 Google 타일 엔드포인트(`mt0~3.google.com/vt`)를 쓴다. API 키·할당량·과금을 타지 않는 대신 **Google Maps Platform 약관이 허용하는 경로가 아니고, 막히면 예고 없이 끊긴다.** 원본 GeoMeasure와 화면을 맞추기 위해 위험을 알고 채택했다(2026-08-06). 끊기면 이 레이어만 제거하고 기본값을 `위성`으로 되돌리면 된다 — 이미지 한계 잠금은 공식 API만 쓰므로 그대로 살아있다.

### 모드

지도 클릭의 주인이 셋 중 하나다. 상단 고정 바에서 전환한다.

| 모드 | 지도 클릭 |
|---|---|
| 📏 측정 | 측정 지점 추가 |
| ⬟ 영역 | 다각형 꼭짓점 추가 (**첫 꼭짓점을 다시 클릭**하면 닫힘) |
| 👁 보기 | 무시 (라벨 드래그는 가능) |

> 영역을 닫는 방법이 K와 다르다. K(카카오)는 더블클릭·우클릭, G(구글)는 첫 꼭짓점 재클릭이다.
> G의 영역 그리기는 **직접 구현**이다 — 구글이 Maps JS 3.65에서 `drawing` 라이브러리를 걷어냈다(CLAUDE.md §5.6). 조작법은 그 전과 같다.

### 저장 포맷

자체 JSON이 아니라 **GeoJSON**을 쓴다. 지도 엔진을 바꿔도 현장 데이터가 살아남아야 하기 때문이고, 그 덕에 **K와 G가 파일을 그대로 주고받는다.**

| 항목 | geometry | properties |
|---|---|---|
| GW 커버리지 | Point | radius, label, name, color, **pid**, **photos** |
| 영역 | Polygon | name, desc, fillColor, strokeColor, opacity, labelPos |
| 텍스트 | Point | text, fontSize |
| 측정 경로 | LineString | — |

거리·면적처럼 **계산으로 나오는 값은 저장하지 않는다**(좌표를 옮겼을 때 어긋난 파일이 된다). 반경은 사용자가 정한 값이라 저장한다. 사진도 같다 — 계산이 아니라 사용자가 넣은 것이라 저장한다. 경로 LineString은 외부 뷰어용으로 내보내되, 불러올 때는 무시하고 GW 지점에서 다시 그린다.

- `pid` — 지점의 안정적 id. 사진을 브라우저 안에서 지점과 이어붙이는 열쇠다.
- `photos` — **배열**(`[{ "uri": "data:image/jpeg;base64,…", "name": "원본파일명.jpg" }, …]`). 설치 사진은 전경/근접/명판 식으로 여러 장이 되므로 처음부터 배열로 둔다. 단수로 뒀다가 나중에 바꾸면 이미 나간 파일과 호환이 깨진다.
  - `name` = **원본 파일명**. 현장에서 파일명 자체에 정보를 담아 찍는다(예: `색달목장_방목지_언덕2_D4F98D066F1D_260713.jpg` — 목장·구역·지점·MAC·날짜). 리사이즈하면 EXIF가 통째로 날아가므로 **파일명이 남는 유일한 촬영 맥락**이다. 이름이 없으면 키 자체가 빠진다.
  - 항목이 문자열(`"data:image/jpeg;base64,…"`)인 초기 형식도 그대로 읽는다(그때는 이름이 빈 값).

**역호환**: `photos`·`pid`가 없는 기존 파일도 그대로 열린다. 반대로 사진을 모르는 구버전·외부 뷰어가 새 파일을 열어도 `properties`는 GeoJSON 자유 필드라 무시될 뿐이고 좌표·반경·영역은 그대로 산다.

`properties.app`은 표기용일 뿐 **불러오기가 검사하지 않는다** — K가 내보낸 파일이 그대로 열린다. 불러오기는 신뢰 경계로 취급해 좌표 범위·타입·필수 필드를 검증하고, 버린 항목은 사유를 화면에 남긴다. 사진은 여기에 더해 `data:image/(jpeg|png|webp);base64,` 접두어·한 장 2MB·지점당 20장으로 제한한다(외부 파일의 문자열이 `<img src>`로 DOM에 들어가는 유일한 경로다).

> ⚠️ **localStorage 자동저장 키는 K와 다르다**(`geomeasure.g.v1`). 같은 호스트에 두 판을 올리면 localStorage를 공유하므로, 키가 같으면 한쪽 작업이 다른 쪽을 덮어쓴다. 두 판 사이의 데이터 이동은 GeoJSON이 담당한다.
> **사진 IndexedDB 이름도 같은 이유로 다르다**(`geomeasure-g-photos` ↔ K `geomeasure-photos`).

### 위치 고정

모바일에서 **두 손가락으로 확대할 때 첫 손가락이 지점·라벨 위에 떨어지면 그게 드래그로 잡혀** 좌표가 바뀌는 사고가 있었다. 측정 도구에서 좌표가 조용히 바뀌는 건 결과가 거짓말이 되는 것이라 두 가지로 막는다.

- **텍스트·영역 라벨** — 잠금과 무관하게 **손가락이 둘 이상이면 드래그를 시작하지 않는다.** 드래그 도중 두 번째 손가락이 들어오면 옮기던 것을 원래 자리로 되돌리고 저장하지 않는다. 이건 우리 코드(`makeDraggableLabel`)라 근본 원인을 고칠 수 있었다.
- **지점 마커** — 터치 처리가 Google Maps SDK 안이라 손댈 수 없다. `setDraggable(false)`가 유일한 수단이라 잠금 스위치를 둔다.

자동 규칙:

| 상황 | 기본값 |
|---|---|
| 빈 상태에서 시작 | **해제** — 탭으로 찍고 드래그로 미세조정하는 게 정상 흐름이다 |
| 파일·드라이브에서 가져옴 | **잠금** |
| 새로고침 후 자동저장 복원 | **잠금** |
| 전체 초기화 | **해제** |

가져오기와 복원을 같이 묶는 이유는 둘 다 **이번 세션에 내가 찍은 게 아닌** 작업이고, 그때 하는 일이 편집이 아니라 보기·사진 붙이기라 핀치를 제일 많이 쓰기 때문이다. 모바일 브라우저는 탭을 잘 죽여서 복원이 흔한데, 복원된 작업은 가져온 것만큼 잃으면 안 된다.

- **잠금 상태는 저장하지 않는다.** 새로고침하면 위 규칙으로 다시 정해진다 — 상태를 하나 더 들고 있을 이유가 없고, 자동저장 GeoJSON 포맷도 K와 그대로 유지된다.
- 잠겨 있어도 **지점 추가·이름 편집·사진 첨부·순서 변경은 그대로 된다.** 막는 것은 드래그 이동뿐이다.

### 사진 첨부

이 도구는 "설치 **전** 위치 계산"인데 사진은 "설치 **후** 기록"이라 두 시점이 갈린다. 그래서 **기존 GeoJSON 불러오기 → 지점 선택해 사진 첨부 → 내보내기**의 왕복이 핵심이고, 파일 하나로 오간다(zip을 쓰지 않는 이유이기도 하다 — 브라우저에 zip 생성 표준이 없고, JPEG는 이미 압축돼 있어 줄지도 않는다).

사진의 주인은 **지점과 텍스트 둘 다**다. 지점이 아닌 자리(출입구·배전반·전신주)를 찍어 두려면 텍스트를 놓고 거기 붙인다. 리사이즈·저장·검증·확대 보기는 양쪽이 같은 코드를 지나간다.

- 첨부: 패널 목록의 📷 또는 지도에서 마커 클릭 → 팝업의 **📷 사진 추가** (여러 장 동시 선택 가능)
  - 폰에서는 OS 선택창이 **촬영 / 앨범 / 파일**을 모두 제시한다. `capture="environment"`를 쓰면 카메라가 한 번에 열리지만 UA에 따라 앨범 선택지가 사라져서 채택하지 않았다.
- 사진이 있는 지점은 지도 마커에 **카메라 배지**가, 텍스트는 라벨 안에 **📷 n** 이 붙는다. 패널을 열어야만 보이면 현장에서 사진의 존재 자체를 놓친다
- 저장 위치가 둘로 갈린다 — 목적이 다르기 때문이다

| | 어디에 | 형식 | 왜 |
|---|---|---|---|
| 자동저장 | IndexedDB | Blob 그대로 | localStorage는 origin당 약 5MB 고정이고 K판과 나눠 쓴다. 사진을 넣으면 몇 장 만에 자동저장이 통째로 죽어 **좌표까지 유실**된다 |
| 내보내기 | GeoJSON 파일 | base64 data URI | 파일 하나로 오가야 하므로 |

- 원본을 넣지 않는다: **최장변 1280px · JPEG 품질 0.75**로 리사이즈한다(약 250KB). 목적이 설치 상태 기록이라 이걸로 충분하다.
- 리사이즈는 canvas 재인코딩이라 **EXIF가 통째로 제거된다** — 촬영 GPS·기기정보가 내보낸 파일에 실리지 않는다(의도한 이득). 대신 회전정보도 같이 사라지므로 `createImageBitmap(file,{imageOrientation:'from-image'})`으로 먼저 회전을 적용한다. 이게 빠지면 세로로 찍은 폰 사진이 90도 눕는다.
- EXIF가 사라지는 대신 **원본 파일명을 보존한다**. 썸네일에 마우스를 올리면(title), 확대 보기에서는 사진 아래에 글자로 보인다.
- 지점·텍스트를 지우면 그 사진도 IndexedDB에서 같이 지운다. 주인 없는 사진은 다음 실행 때 정리된다.
- 사진을 잇는 열쇠는 `pid`이고 GeoJSON `properties.pid`로 같이 나간다. **`pid`가 없던 시절의 파일(K 구판·외부 제작)은 경고 없이 읽히고** 불러올 때 `pid`를 새로 만든다.

### 드라이브에서 불러오기

목장 파일을 드라이브에 두고 **링크 하나로 현장 폰에 띄우는** 용도다. 다운로드 → 파일선택 두 단계를 없앤 것이고, 기존 불러오기와 하류가 같아 검증·자동저장 동작도 같다.

- 저장/불러오기 카드의 입력창에 **드라이브 공유 링크를 붙여넣고 `☁ 가져오기`**
  - 받는 형태: `/file/d/<ID>/view` · `/open?id=<ID>` · `uc?export=download&id=<ID>` · 파일 ID 단독
- 링크가 유효하면 아래에 **`?gd=<파일ID>` 주소와 복사 버튼**이 뜬다. 그 주소를 열면 지도가 바로 그려진다.
  - 주소는 `location`에서 만든다 — 라이브에서 만들면 라이브 주소, `-dev`에서 만들면 dev 주소가 나온다.
  - 링크 통째가 아니라 **파일 ID**를 싣는다. 링크를 넣으면 URL 안에 URL이 들어가 인코딩으로 두 배 넘게 길어지는데, ID 단독도 받으므로 잃는 게 없다.
- 파일 공유는 **"링크가 있는 모든 사용자" + 역할 "뷰어"**. 다운로드만 하므로 편집자 권한은 필요 없다.

**왜 로그인이 없나** — 공유 링크를 그대로 `fetch`하면 CORS로 막혀(응답에 `Access-Control-Allow-Origin`이 없다) Drive API를 쓴다. 여기에 OAuth를 붙이면 비공개 파일도 열리지만, **링크를 받는 사람마다** 구글 로그인 + 테스트 사용자 사전등록 + "확인되지 않은 앱" 경고를 거쳐야 해서 "링크 하나로 열린다"는 목적과 정면으로 어긋난다. 그래서 API 키(익명 요청)를 쓰고, 공개 공유를 전제로 둔다. 비공개 자료를 다뤄야 할 일이 생기면 그때 OAuth를 꺼낸다.

링크에서 **파일 ID만 떼어** 쓰므로 요청처가 `googleapis.com` 하나로 고정된다. 링크는 URL 파라미터로도 들어오는(= 남이 정하는) 값이라 임의 URL을 그대로 `fetch`하지 않는 것이 신뢰 경계다.

`?gd=`로 열 때 복원된 작업이 있으면 확인을 받는다. 실제 초기화는 응답을 파싱해 **읽을 항목이 있음을 확인한 뒤에만** 일어나므로, 응답이 GeoJSON이 아니어도 화면의 작업은 그대로 남는다.

| 증상 | 원인 |
|---|---|
| `404` | 링크 오타이거나 공유가 "링크가 있는 모든 사용자"가 아님 — 구글이 비공개 파일에도 404를 주므로(존재 은닉) 코드로 못 가른다 |
| `403` | API 키 리퍼러 제한·할당량·Drive API 사용 설정 |

> **K와 다른 점**: K는 지도가 카카오라 구글 키를 `GDRIVE_KEY`로 따로 뒀지만, G는 지도 키가 이미 구글 키다. 상수를 하나 더 두지 않고 `apiKey()`를 Maps와 Drive가 공유한다 — `?key=` 임시 확인도 양쪽에 같이 걸린다.

## 사용 / 설정

정적 HTML 한 파일이라 별도 빌드가 필요 없다. 웹서버에 `index.html`을 올리면 동작한다.

단, **Google Maps JavaScript API 키**가 필요하다. [Google Cloud Console](https://console.cloud.google.com/google/maps-apis)에서 아래를 설정한다. **하나라도 빠지면 지도가 안 뜬다.**

### 1. API 사용 설정

- **Maps JavaScript API** — 지도 표시 (필수)
- **Geocoding API** — 장소/주소 검색 (검색을 안 쓸 거면 생략 가능)
- **[Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com)** — 드라이브에서 불러오기 (안 켜면 그 버튼만 실패하고 나머지는 다 돈다)
  - 키 제한의 **API 제한 드롭다운은 "사용 설정된" API만 보여준다.** 이걸 먼저 켜지 않으면 목록에 `Google Drive API`가 안 나온다(`Google Cloud APIs`는 별개 항목이라 Drive를 포함하지 않는다).
  - Drive API는 **과금 SKU가 아니다** — 무료 한도만 있고 초과하면 거부된다. Maps처럼 할당량 상한을 걸 이유가 없다.

### 2. 결제 계정 연결

**무료 한도만 쓰더라도 결제 계정(해외결제 가능 카드) 연결이 필수다.** 카카오와 결정적으로 다른 점이다.

### 3. 키 발급 후 코드에 넣기

`index.html`의 `GMAPS_KEY` 상수에 JavaScript API 키를 넣는다.

```js
const GMAPS_KEY='여기에_키';
```

임시 확인은 주소 끝에 `?key=발급키`를 붙여도 된다(파일을 고치지 않아도 됨).

### 4. 키 제한 — HTTP 리퍼러

키 제한을 **HTTP 리퍼러(웹사이트)** 로 설정하고 서비스할 주소를 등록한다. 구글 JS 키도 카카오와 마찬가지로 클라이언트에 노출되는 것이 정상이며, 리퍼러 제한이 보호 수단이다.

- 개발용 사본(`/bovicare-gmapgoogle-dev/*`)도 **따로 등록해야 한다.** 카카오는 origin 단위로 등록해 경로가 달라도 되지만 구글은 경로까지 좁힐 수 있어, 라이브 경로만 등록해 두면 dev에서 `RefererNotAllowed`가 난다(CLAUDE.md §3.4).

키가 실제로 통하는지는 **브라우저 없이** 확인할 수 있다. 리퍼러 제한은 헤더 기반이라 서버에서도 재현된다 — 지도(Maps JS)는 이 방법이 안 통하지만(CLAUDE.md §3.3), Drive는 된다.

```bash
curl -s -H "Referer: https://yepark.co.kr/bovicare-gmapgoogle/" \
  "https://www.googleapis.com/drive/v3/files/<가짜ID>?alt=media&key=<KEY>" | head -5
# 404 File not found  → 키·API 사용설정·리퍼러 전부 정상 (파일 ID만 가짜)
# 403 API_KEY_HTTP_REFERRER_BLOCKED → 리퍼러 제한에 그 주소가 없다
```

### 5. 할당량 상한 — 과금 방지 (중요)

**예산(Budget) 알림은 사용을 막지 않는다.** 알림만 보내고 과금은 계속된다. 실제로 막으려면 **할당량(Quota) 상한**을 걸어야 한다.

| | 월 무료 | 일 상한 권장 |
|---|---|---|
| Maps JavaScript API (Dynamic Maps) | 10,000 | 300 |
| Geocoding API | 10,000 | 300 |

무료 한도는 **월** 단위인데 할당량 설정은 **일** 단위다. `10,000 ÷ 31 ≈ 322`이므로 300 정도로 잡으면 월 무료를 넘지 않는다. API마다 별도 SKU라 **각각 걸어야** 한다.

한도를 넘으면 지도가 안 뜨고 화면에 안내가 표시된다 — 과금이 아니라 정지다.

### 지도가 안 뜰 때

화면에 현재 origin과 함께 원인 후보가 표시된다. 브라우저 콘솔 오류로도 가릴 수 있다:

| 오류 | 원인 | 조치 |
|---|---|---|
| `BillingNotEnabled` | 결제 계정 미연결 | 2번 |
| `RefererNotAllowed` | 리퍼러 제한에 현재 주소 없음 | 4번 |
| `ApiNotActivated` | Maps JavaScript API 미활성화 | 1번 |
| `InvalidKey` | 키 문자열 오류 | 3번 |
| `OverQuota` | 할당량 초과 | 5번 (의도한 정지) |
| 검색만 `REQUEST_DENIED` | Geocoding API 미활성화 | 1번 |
| 검색 시 "지도 로딩 후 다시 시도하세요" | 키 문제가 아니다 — `initMap`이 중간에 끊겨 `geocoder`가 안 만들어진 것 | 콘솔에서 `초기화 실패:` 경고를 찾는다. 화면에도 같은 내용이 뜬다 (CLAUDE.md §5.6) |

## 자체 점검

지도 SDK 없이 순수 로직만 확인한다. **API 키가 없어도 돌아간다** — 이 저장소는 키 확보 전에 작성됐으므로 특히 중요하다.

**브라우저에서 거리만 빠르게 보기**

```
index.html?selfcheck=1
```

**전체 검증 (거리 · 면적 · GeoJSON 파싱 · 입력 검증 · K 호환)**

```
node selfcheck.test.js
```

의존성·프레임워크 없이 `node`만 있으면 된다. `index.html`의 인라인 스크립트를 **매번 그대로 추출해** 돌리므로 사본이 갈라지지 않는다.

기준값은 원본 도구로 측정한 용춘목장 3지점(A↔B 196.7 m · B↔C 237.9 m · C↔A 355.5 m)이며, **K와 같은 값이어야 한다** — 다르면 두 판이 파일을 주고받는 의미가 없어진다. K가 내보낸 파일을 그대로 읽는지, 남반구·서반구 음수 좌표가 통과하는지도 함께 검증한다.

## 검증 상태

| 항목 | 상태 |
|---|---|
| 순수 로직 (거리·면적·GeoJSON·입력검증) | ✅ `node selfcheck.test.js` 60건 통과 |
| K와의 계산 결과 일치 | ✅ 대조 확인 |
| 웹서버 배포 (경로·문서차단·위치헤더) | ✅ 2026-08-06 적용 확인 (아래 «배포») |
| 위성+ 타일 좌표 계산 | ✅ selfcheck 6건 + 실제 타일 URL 200 응답 확인 |
| **지도 렌더·드로잉·측위** | ⏸ **미검증** — 실제 브라우저 확인 필요 |

배포는 끝났지만 **지도가 실제로 뜨는지는 아직 사람 눈으로 확인되지 않았다.** 키 인증(리퍼러·결제·API 활성화)은 브라우저에서만 판정되며, `curl`로는 가릴 수 없다 — 직접 호출한 `AuthenticationService`는 리퍼러와 무관하게 같은 오류를 돌려주므로 검증 수단이 되지 못한다.

브라우저로 서비스 주소를 열어 다음을 확인한다: 지도 표시 · 지점 추가/드래그 · 반경원 · 영역 그리기(첫 꼭짓점 재클릭으로 닫기) · 라벨 드래그 · 지도타입 5종 · **위성+에서 21~22레벨까지 확대해도 "이미지가 없습니다"가 안 뜨는지** · **위성 모드에서 한계 안내가 뜨고 더 확대되지 않는지** · 검색 · GPS · **사진 첨부(폰에서 촬영/앨범 둘 다 되는지, 세로 사진이 눕지 않는지, 내보내기→불러오기 왕복에서 살아남는지)** · K 파일 불러오기. 지도가 회색이면 화면에 원인이 표시되므로 «지도가 안 뜰 때» 표로 넘어간다.

> 기본값이 위성+로 바뀐 뒤로는 **키가 잘못돼도 타일은 그려진다**(그 레이어는 키를 타지 않는다). 키 확인은 화면의 인증 오류 안내와 검색 동작으로 판정한다.
